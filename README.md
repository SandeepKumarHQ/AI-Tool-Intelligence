# AI Tool Intelligence — Evidence-led tool and software catalog

Public-facing technology evaluations for enterprise AI architects. This repository **does not originate independent factual truth**: evaluations produce attributed proposals for the private Knowledgebase, and public comparisons cite approved `kb_refs` and dated primary sources.

## Questions this catalog answers
What does a tool do? Who operates it? What are licensing and deployment constraints? What are the integration/security boundaries? Does it work on representative tasks? What is the true cost/risk? What changed since the previous review?

## Domains
Agent frameworks, MCP clients/servers, model providers, coding agents, browser automation, local inference, observability/evaluation, RAG/retrieval, security, integration platforms, data orchestration and infrastructure.

## Editorial workflow
`AI-Radar discovery → Knowledgebase evidence review → reproducible tool evaluation → Knowledgebase experiment contribution → approved catalog entry → impact reevaluation when releases change`.

See [review rubric](evaluations/RUBRIC.md) and [catalog template](catalog/TEMPLATE.md). Evaluations must separate maintainers' claims from independent findings.

**Status:** structural foundation only; no reviewed tool profiles or benchmarks are represented as complete.
